🚀 Como funciona a arquitetura Cloudflare Pages com Functions

1. Frontend Estático (`public/`) A pasta public/ é servida instantaneamente pela CDN global da Cloudflare sem necessidade de rodar npm run build.
2. Pages Functions (`functions/api/`) As rotas /api/lead e /api/relatorio rodam como serverless functions automáticas com acesso ao banco D1.
3. Script Local Baileys (`bridge/`) Roda na sua máquina com Node.js, escuta o WhatsApp e faz POST https://seu-app.pages.dev/api/lead.
